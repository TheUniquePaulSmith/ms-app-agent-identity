Gateway scenario Proposal.md layers 4 + 5

Local LLM, MCP server in Azure behind API Management. Tool calls run as a second agent identity from the same blueprint. Every call is checked by the gateway (kill list, rate limit, coarse AuthZEN decision), by the MCP server (AuthZEN per tool and claim) and by the Claims API (AuthZEN per record). Users are evaluated through their Entra group membership.
